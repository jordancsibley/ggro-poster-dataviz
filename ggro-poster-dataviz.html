# Write function to print out unique values and summary stats 
qc_summary <- function(data) {
  for (col in names(data)) {
    cat("\n---", col_name, "---\n")
    
    if (is.character(data[[col_name]])) {
      unique_vals <- unique(data[[col_name]])
      cat("Unique values:\n")
      print(unique_vals)
    } else if (is.numeric(data[[col_name]])) {
      cat("Summary:\n")
      print(summary(data[[col_name]]))
    } else {
      cat("Column is of type:", class(data[[col_name]]), "- not character or numeric.\n")
    }
  }
}

Context for this density plot:

This kind of plot reflects distribution of observation dates, not the actual count of birds.

“Each ridge shows the estimated distribution of observation dates for a species in that year group, normalized to area = 1 for that species–year group (weights influence shape, but the total area of the curve is still 1). The result is a smooth curve that answers “When during the season do sightings tend to cluster?”

Because density curves are normalized to integrate to 1, a taller peak means the dates are more tightly concentrated around that time. It doesn’t mean there were more total birds—just that the sightings (weighted by counts) are more focused in time.

So when looking at heights of ridges: Peaks show timing and concentration (weighted by Daily Count); heights are normalized per species–year group and do not reflect totals.

This plot does not answer which bird was seen the most often and instead addresses when during the season do sightings tend to cluster.
